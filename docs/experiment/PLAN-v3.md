# Kimodo Maker v3 · 영어 지시가 실제 모션에서 이행되는 조건

**첫 결정은 학습할 가중치가 아니라 실패가 발생하는 단계다.** 같은 영어 지시와 시드에서 ① 원본이 어떤 모션을 뽑는지, ② 정확한 공간 목표를 주면 원본이 그 동작을 수행하는지, ③ 앱이 문장만 받아도 그 목표를 만들 수 있는지를 차례로 검증한다. 영어 단일 동작의 지시 이행과 시각 품질이 제품 목표다. 한국어·경량화는 영어 기준선 확정 후 별도 실험으로 둔다. 복합 행동의 순서는 이번 인수 범위 밖이다.

이 문서는 사전등록 **설계안**이다. 아래 측정치와 새로 제안하는 실험 규모·문턱값을 구분한다. v1과 v2의 점수, 채점 코드, 봉인 세트, 출시 상태는 역사 기록으로 보존한다.

## 3. 한 장의 4090으로 먼저 구분할 세 가지 가설

**제안하는 파일럿**은 영어 12그룹 × 3시드(17, 43, 97)다. 4그룹은 자기 몸의 특정 위치에 닿는 동작, 4그룹은 이동·회전, 4그룹은 기존 성공 동작을 포함한 자유 동작으로 고른다. 좌우 대립, 회전 부호 경계, 손대지 않아야 할 비대상 문장을 포함한다. 양쪽 표현·바꿔쓰기·동일 테이크는 같은 분할에 둔다. 12그룹은 고장 진단용이며 일반화 점수로 쓰지 않는다. 새 후보를 보기 전에 대상, 필수 조건, 시드, 키프레임을 넣을 시점, 입력 출처, 어느 클립이 양성 대조인지 잠근다.

| 조건 | 조건 입력과 비교 목적 |
| --- | --- |
| A · 공식 앱 | 원문, 공식 LLM2Vec, 제약 없음. 각 시드의 결과를 전부 보관한다. 한 시드에서만 성공하면 표본 선택 여지가 있고 세 시드 모두 실패해도 능력의 상한은 알 수 없다. |
| B · 사람이 부여한 공간 목표 | A와 동일한 문장·시드에 독립적으로 작성한 도달 가능한 손발/전신 키프레임 또는 루트 경로 한 종류를 입력한다. 시작·끝을 통째로 고정하지 않는다. 비대상에는 빈 제약을 준다. A/B는 생성기가 정확한 목표를 받았을 때의 개선 여지를 측정한다. **진단 전용**이다. |
| C · 앱이 만든 공간 목표 | B에 효과가 있을 때만 진행한다. 요청의 문장, 초기 골격, 사전에 고정한 동작 사전 또는 train 전용 포즈 자료로 목표를 만든다. 동작·좌우·해부학적 목표·지지발·시점을 추출하고 초기 자세 기준 좌표를 Kimodo 제약으로 변환한다. 모호하거나 지원 범위 밖이면 A로 보낸다. 실행 시 판정기, 정답 프레임, 평가용 모캡, 문장 ID 목록에 접근하지 않는다. 파싱 오류·fallback도 전부 분모에 넣는다. |

예컨대 '오른발을 머리 옆까지'는 발의 세계 Y만 지정하면 머리를 숙여 조건을 채울 수 있다. 목표 자세에서 예상하는 발–머리 상대 위치와 몸통 자세, 지지발을 먼저 정의한다. 안전하게 수행된 참조 포즈나 관절 가동범위를 지킨 IK로 B의 희소 키프레임을 만들고 정지 화면을 먼저 검증한다. Kimodo의 손발 제약은 임의의 상대 거리식을 직접 받지 않는다. 해당 골격의 local_joints_rot(axis–angle)와 root_positions 등 공식 형식으로 변환한다. 모델에서 생성된 접촉 전후의 접근·복귀, 균형, 지지발까지 전 구간을 채점한다. 원래 잘되던 자유 동작은 A와 같은 경로가 같은 시드에서 재현되어야 한다. [Maker 생성 경로](../../backend/engine.py) · [공식 제약 포맷](https://github.com/nv-tlabs/kimodo/blob/e1c219c99b4b94ba48be1fb6a1cbc64ecee4c954/docs/source/user_guide/constraints.md)

1. **A의 SOMA는 맞고 VRM만 틀리면** 같은 테이크의 좌표·본 매핑·리타게팅을 수정하고 다시 재생한다. 이득은 뷰어 변경으로 기록한다.
2. **합성 대조는 맞지만 B도 실패하면** 한 그룹으로 줄여 캡처 원본 → 앱 제약 변환 → 모델 입력 → 후처리 전·후 궤적을 추적한다. 좌표계·시점·목표 도달 가능성을 고친 뒤에도 B가 재현성 있게 실패하면 이 경로는 보류한다. 이 결과만으로 인코더나 생성기의 학습을 시작하지 않는다.
3. **B 성공, C 실패면** 사람이 정한 구조와 C의 구조를 필드별로 대조한다. 올바른 B 목표를 그대로 주입했을 때 성공이 복구되는지 확인하고, 오류가 모인 한 단계만 수정한다. C가 자동화되어도 이는 제약을 이용한 제품 개선이다. 텍스트 인코더 개선으로 발표할 수 없다.
4. **B와 C가 성공하면** 개발 세트로 옮긴다. 파일럿 진입 기준 제안은 대상 8그룹 중 서로 다른 2그룹 이상에서 각각 3시드 중 2개 이상 A 실패→후보 성공, 자유 동작 4그룹의 신규 실패 0건이다. 점수는 요구 동작과 시각 품질을 모두 만족한 경우만 센다. 최대 2후보(무학습 C, 아래의 학습 후보 각 1개)까지만 독립 dev에 올린다.

## 4. 인코더 학습이 필요한 경우의 대조 실험

인코더 자체의 기여를 주장하려면 A와 동일하게 **제약 없이 문장만으로 생성**하는 별도 조건 D가 필요하다. 첫 가설은 '자연 캡션과 그 캡션에 대응하는 실제 모션으로 조건 잔차를 학습하면, 낯선 표현에서도 지정한 관절과 진폭을 더 잘 따른다'이다.

- 권한이 있는 BONES-SEED 자연 캡션과 **해당 테이크의 실제 SOMA 모션**을 소량 확보한다. 로컬 v2 기록은 CSV·Parquet 확보까지만 확인한다. 모션 없이 캡션만 있으면 이 지도 실험은 개시하지 않는다. 테이크·미러·유사 캡션을 그룹으로 묶고 실제 앱 외부 평가와 분리한다. 캡션을 바꿔 섞은 대조도 준비한다.
- LLM2Vec·Kimodo를 고정하고 공식 영어 조건에 더할 작은 잔차 모듈만 0에서 시작한다. 첫 배치에서 잔차 0이 공식 경로와 같은지, 동결한 denoiser를 거쳐 잔차 파라미터까지 유한한 기울기가 전달되는지 검증한다. 일반 추론 함수의 no_grad 경로를 그대로 학습 진입점으로 쓰지 않는다.
- 실제 모션을 리비전에 맞는 motion_rep로 변환해 복원 오차를 확인한다. 동일한 노이즈·시점에서 정렬된 캡션의 모션 복원 손실을 줄이고, 캡션을 섞었을 때보다 해당 모션을 더 잘 설명하는지 측정한다. D의 제안 손실은 공식 denoiser의 예측 대상에 맞춘 복원 오차와 기존 성공군의 조건 잔차 크기 벌점이다. 시점·손실 가중치·소형 샤드·예산은 시작 전 고정한다. 교사 벡터 MSE는 진단으로 기록한다.
- **본학습 진입**은 작은 샤드에서 학습·재개가 되고, 미학습 파일럿 그룹에서 D가 위의 동작·품질 기준을 통과할 때다. 손실만 하락하거나 셔플 대조와 분리되지 않으면 장기 실행을 중단한다. 적용 범위가 겹치는 C가 있으면 D와 실제 모션·비용을 같이 비교한다. 한국어와 EmbeddingGemma 2는 이후 같은 뜻의 문장으로 ① 공식 영어, ② 고정 한국어→영어 번역 + 공식 경로, ③ 경량 후보 영어, ④ 같은 경량 후보 한국어를 비교한다. ①–③은 인코더 교체 손실, ③–④는 후보의 언어 간 차이, ②–④는 한국어 사용자 관점의 대안 비교다.

## 5. 출시 결정

새 영어 앱 프롬프트를 전향적으로 수집한다. 기존 17문장, 반복해서 본 v2 dev, B 제작에 쓴 포즈와 동계열 자료는 회귀·파일럿에만 쓴다. BONES 캡션은 외부 분포 진단용으로 따로 보고한다. 새 dev와 봉인 test를 그룹 단위로 먼저 나누고 두 세트에서 독립적으로 같은 기준을 요구한다. 4개 층은 이동·전신, 자세·바닥, 방향·회전, 사지·제스처다. 사용자 입력이 자유로운 앱에서는 fallback 비율도 층별로 함께 보고한다.

**제안 인수선.** 각 세트의 시작 규모는 층별 16그룹, 그룹당 3시드다. 독립 파일럿에서 관측한 그룹별 쌍차이의 변동으로 필요한 정밀도를 검토하고 후보를 보기 전에 최종 표본 수와 예산을 잠근다. 2인의 독립 블라인드 평가자가 이행과 자연스러움을 각각 평정한다. 순서 무작위화, 불일치 시 제3평가자 중재, 판독 불가면 재렌더 후에도 판독 불가인 경우 증거 불충분으로 정한다. 생성 실패는 실패다. 건강한 기존 성공군은 신규 평가 후보의 출력과 무관하게 별도 파일럿에서 고정한다.

각 클립의 성공은 **이행 AND 자연스러움**이다. delta는 같은 프롬프트·시드에서 후보 성공(0/1) − A 성공(0/1)을 구해 시드, 그룹, 네 층 순으로 동일 가중 평균한 %p 값이다. 그룹을 층 안에서 복원추출하고 세 시드와 두 arm을 함께 옮기는 paired bootstrap 10,000회, RNG 20261123, 백분위 2.5를 L95로 고정한다. 다음은 프로토콜 수준 TLA+ 술어다. 수치는 실험 결과가 아니며 잠금 전 변경할 수 있다. 비율은 정수 분자·분모 또는 보수적으로 내림한 basis point(1%p = 100 bp)로 평가한다.

```tla
Benefit(m) == /\ m.jointDeltaBP >= 500 /\ m.jointLower95BP > 0
              /\ m.intentDeltaBP >= 0 /\ m.qualityDeltaBP >= 0
              /\ \A k \in Strata : m.stratumDeltaBP[k] >= -500
              /\ m.knownGoodDeltaBP >= -500
Gate(m) == /\ m.complete /\ m.blind /\ m.noLeak /\ Benefit(m)
           /\ m.vrmOK /\ m.exportsOK
           /\ 100 * m.p95ms <= 120 * m.stockP95ms /\ m.fits4090
MayOpenTest == devPassed /\ frozen /\ testOpens = 0
Accepted == devPassed /\ frozen /\ testOpens = 1 /\ sameCandidate /\ Gate(test)
```

층·기존 성공군의 −5%p는 고정 세트의 관측 퇴화 한도다. 하위군의 통계적 비열등성을 보장하지 않는다. 제약 경로의 파싱·IK·검색, 학습 경로의 인코더도 p95에 포함한다. 동일 4090에서 동시성 1, 배치/캐시 정책, 총 샘플 수, 길이, 스텝, 후처리와 장치 메모리 측정을 잠근다. 후보와 A의 공통 시드는 실패 후 교체하지 않는다. 새 테이크의 VRM 재생과 JSON/BVH/NPZ 왕복 역시 필요하다. 제약 B 또는 정답을 아는 다중 시드 선택 결과는 출시 후보가 될 수 없다.

**실행 순서**는 공개 NPZ 반례 재현 → 채점기 대조 통과 → A/B 파일럿 → 결과에 따라 C 또는 D → 독립 dev → 후보 하나를 동결해 봉인 test 한 번이다. 각 단계에서 입력·코드·체크포인트 해시, 필수 ID별 산출물, 실패와 재개 기록을 남긴다. 사람 평정이나 독립 시험이 없으면 품질은 미판정, 예산 종료 시 마지막 검증된 단계까지만 보고한다.
